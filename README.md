# Operator Index

**Frontier-tech podcasts, read by someone who has to make payroll.**

Great technology podcasts produce *outputs* — "someone should build the crystal ball,"
"that'd be a boom to the legal industry," "I'd buy that." Then the conversation moves on,
because in venture-world an idea's job is to be interesting.

In operator-world an idea's job is to be **sold to someone by Friday.**

This index takes each episode and asks the four questions the room skipped: **who supplies
the data, what does the input cost, what is the actual process, and who writes the check.**

---

## The method

Two passes over each episode.

### Pass 1 — the cue filter

Scan the full transcript for the moments where a gap is stated out loud:

- *"we haven't done that yet"*
- *"nobody's doing this"*
- *"I'd love that" / "I'd buy that"*
- and every place a **capability exists but the application is left open**

Those cues are the raw material. Everything else is context.

### Pass 2 — SIPOC

For every surviving cue, force all five fields:

| | |
|---|---|
| **S**upplier | who has the data / capability |
| **I**nput | what it costs to get, in money and in access |
| **P**rocess | what you'd actually have to build |
| **O**utput | the thing that gets delivered |
| **C**ustomer | **who writes the check** |

> **A blank field is the finding.** If you cannot name the Customer, that is the verdict —
> and it is the single most common blank. Ideas that die here died for a reason worth
> writing down.

SIPOC is a process-mapping methodology (Suppliers → Inputs → Process → Outputs →
Customers). Podcasts hand you the O. This index supplies the S, I, P and C.

### Verdicts

Every idea gets one:

- **REAL** — buyer identifiable, process buildable by a small team
- **INTERESTING, NOT BUILDABLE** — real gap, but needs capital or access you don't have
- **ALREADY CROWDED** — the guest is describing something they or others are shipping
- **FRAMING ONLY** — not a product; a way to think, worth keeping

## What is in here

```
episodes/     one file per episode — the index, the ideas, the operator's read
TEMPLATE.md   the schema every episode file follows
transcripts/  NOT PUBLISHED — gitignored. Working substrate only.
```

**Transcripts are deliberately excluded from this repository.** The words spoken on a
podcast belong to the people who said them. What is published here is an index of facts
(companies, links, timestamps), short attributed quotes, and original commentary — all of
which points back to the source episode. If you want the episode, go listen to it; every
entry links to it.
